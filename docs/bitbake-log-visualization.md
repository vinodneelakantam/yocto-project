# BitBake Log Visualization

Use this guide to visualize BitBake cooker logs in terms of:
- tasks,
- recipes,
- task stages (`do_fetch`, `do_unpack`, `do_compile`, and so on).

## What To Use

Use the repository helper scripts:
- `scripts/generate-bitbake-artifacts.sh` (recommended bundle)
- `scripts/visualize-bitbake-log.py` (log visualization only)

It parses a cooker log and generates:
- an HTML dashboard,
- CSV summaries for recipe/stage and stage-only views,
- optional dependency SVGs from BitBake DOT outputs.

The local wrapper `scripts/local-build.sh` invokes the bundle script
automatically after successful builds (unless `VISUALIZE_BUILD_LOGS=false`).

The bundle script gives you two artifact sets in one run:
- Taskexp-related dependency artifacts generated via `bitbake -g <target>`.
- Python log-visualization artifacts generated from the latest cooker log.

## Inputs

- Cooker log: `build/tmp/log/cooker/<machine>/<timestamp>.log`
- Optional DOT directory: usually `build/` (contains `task-depends.dot` and `pn-depends.dot` if generated by `bitbake -g`).

## Run

```bash
./scripts/generate-bitbake-artifacts.sh core-image-minimal
```

To run Task Explorer UI directly (interactive):

```bash
bitbake -u taskexp <image-or-target>
```

Or from the bundle script (if graphical display is available):

```bash
export RUN_TASKEXP_UI=true
./scripts/generate-bitbake-artifacts.sh core-image-minimal
```

## Outputs

In your selected output directory:
- `report.html`
- `tasks.csv`
- `recipe_stage_summary.csv`
- `stage_summary.csv`
- `meta.json`
- optional `task-depends.svg`
- optional `pn-depends.svg`

## If You Need DOT Graphs

Generate DOT files first:

```bash
bitbake -g <image-or-target>
```

Then rerun the visualization script with `--dot-dir` pointing to the directory
where DOT files exist.

## Buildstats Timing (Recommended)

For stronger stage timing visibility in Yocto itself, enable summary output in
`build/conf/local.conf`:

```conf
INHERIT += "buildstats buildstats-summary"
```

This complements cooker-log visualization by giving timing-focused summaries
from BitBake metadata.
